世界观工坊：iPhone / iPad 免费部署说明

你不需要上架 App Store，也不需要电脑。
推荐使用 iPad 的 Safari 操作，屏幕更大。

一、上传到 Cloudflare Pages
1. 在 Safari 打开 dash.cloudflare.com，注册或登录免费账号。
2. 打开 Workers & Pages。
3. 选择 Create application（创建应用）→ Pages → Direct Upload（直接上传）。
4. 项目名称可填写 novelworld-private。
5. 选择本压缩包 NovelWorld_PWA_FreeDeploy.zip，上传并部署。
6. 部署完成后会得到一个 https://……pages.dev 的网址。

二、安装到桌面
1. 用 Safari 打开 pages.dev 网址。
2. 点 Safari 的分享按钮。
3. 选择“添加到主屏幕”。
4. 打开“作为网页 App 打开”，然后点“添加”。
5. 以后直接点击桌面上的“世界观工坊”图标。

三、隐私和备份
- Cloudflare 上只放程序代码，不保存你写的小说内容。
- 小说内容保存在当前 iPhone 或 iPad 的 Safari 本地数据库中。
- 两台设备不会自动同步。
- 需要换设备时，在“我的”里导出加密备份，分享时选择“存储到文件”，保存到 iCloud Drive；然后在另一台设备导入恢复。
- 删除 Safari 网站数据、卸载网页 App 或系统清理存储，可能清除本地资料，因此务必定期备份。
