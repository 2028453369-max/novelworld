# 世界观工坊 NovelWorld

为小说创作者制作的私人世界观、角色、剧情、地图、图谱、历法与稿件管理工具。

在线地址：<https://2028453369-max.github.io/novelworld/>

## iPhone / iPad 使用

1. 使用 Safari 打开在线地址。
2. 点击 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 从主屏幕图标打开，即可像 App 一样全屏使用。

首次完整打开后，核心网页资源会缓存，可离线继续使用。

## 主要功能

- 28 个细化板块：角色库、形象、关系、组织、角色历程、世界剧情、地图中心、世界运行、世界总纲、力量体系、自然图鉴、经济与货币、灵魂与信仰、文明与社会、知识与技艺、地理与环境、道具信物、羁绊恩怨、剧情线、故事集、稿件库、通讯、提醒、统计、图谱、文字、历法、补档案。
- 每个板块均有适合小说设定的详细字段，可新增、编辑、搜索、复制和删除。
- 地图中心可上传底图，插入城市、村镇、城堡、山脉、森林、水域、遗迹、秘境及自定义标记，并拖动排布。
- 关系图谱自动读取角色、组织、关系和羁绊，生成可拖动节点与连线。
- 世界剧情和角色历程支持时间线展示；历法可自定义纪元、月份、星期、季节与节日。
- 稿件库提供全屏正文编辑、自动保存和字符统计。
- 支持多个作品、本机 PIN 应用锁、全局搜索、到期提醒、设定统计和缺档检查。
- 支持普通 JSON 备份及带密码的 AES-GCM 加密备份，可保存到“文件”或 iCloud Drive。

## 数据与隐私

- GitHub 仓库只保存网页程序代码，不保存你在工具中填写的角色、剧情、地图或正文。
- 创作资料默认存放在当前浏览器的 IndexedDB 本地数据库中，程序没有账号、分析统计或外部内容接口。
- 本机 PIN 是打开应用时的访问门槛；加密备份文件使用 AES-GCM 加密。
- 清除 Safari 网站数据、删除主屏幕网页 App、设备损坏或更换设备，都可能导致本机资料丢失。请定期在“我的”中导出加密备份。
- 不同浏览器或不同设备不会自动同步；需要通过导出与导入备份迁移资料。

## 技术结构

纯静态 HTML、CSS 与原生 JavaScript，无服务器数据库、无第三方运行依赖。使用 IndexedDB 保存内容，Service Worker 提供离线缓存，可部署在 GitHub Pages。
